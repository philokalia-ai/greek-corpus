# Τύπος και δημοσιογραφία

Συνέχεια από την 1η σελίδα στρατιώηση τών ιδεών είναι τό μεγάλο κατόρθωμα τού τύπου.

Εδώ ακριβώς είναι ή μεγάλη εύθύνη μας. Νά δίνουμε ποιότητα στην έφημερίδα πού γράφουμε, να την γράφουμε με αίσθηση της εύθύνης μας, και να την κάνουμε αληθινό σχολείο για τους συνανθρώπους μας.

...Ο ΡΟΛΟΣ ΤΗΣ ΕΦΗΜΕΡΙΔΑΣ

Μιά έφημερίδα πρέπει να είναι άγρυπνος κριτής για τις έκφυγιες τών αρχών, και διεκδικητής για τά διάφορα κοινωνικά στρώματα. Έπειδή δε, ό τύπος έπιδρά στην πολιτική συνείδηση τών πολιτών, πρέπει να δοηθάει σωστά τό άτομο, να ξεκαθαρίζει τις προτιμήσεις του. Νά δοηθάει στη διάδοση τών ηθικών αξιών και να συμμετέχει έτσι στη λειτουργία της κοινωνίας.

Μέ τις εικόνες και τ' αφηγήματά της να δοηθάει τά άτομα να χαλαρώνουν ψυχικά, να ψυχαγωγούν, να τέρ πουν.

Τά ανήθεια και δίαια είδησεογραφικά γεγονότα να δίλωται σαν παράδειγμα για άποφυγή.

Νά μεταδίδει γνώσεις. Νά είναι χρήσιμο όργανο για την καθημερινή ζωή. Νά γράφει λίγα για να βαραίνουν πολλά.

Απαγορεύεται να διαστρεθλώνει τά γεγονότα, να συκοφαντεί, να υπερβάλει, να ψεύδεται.

Νά προωθεί τά γράμματα, τις καλές πράξεις και την άμυλα, διότι μέσα από αυτά θα πηγάσει ή εύνομου μένη πολιτεία.
