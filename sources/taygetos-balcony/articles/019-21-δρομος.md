# ΔΡΟΜΟΣ»:

«Γκαμήλα Ἀράπης φόρτωσε δαριά και τη ρωτούσε:

— Θέλεις να πάς ἀνήφορο ἢ προτιμάς κατήφορο;»
Και μ' ἐξυπνάδα ἀπάντησε αὐτή που ἀγκομαχούσε:

— «Και χάθηκαν, ἀρέντη μου, ἡ ὅσα στράτα ὡς τόσο, κι' ἐγώ να ξαλαφρώσω;»
