# Για τους αρμόδιους

Είχαμε γράψει για τις λακκούδες του δρόμου Σπάρτης - Καραδά - Καστόρι, ευτυχώς επουλώθηκαν και οι οδηγίες κοκλοφορούν σκάνδυνα. Φέτος θα μιναργήθηκαν λακκούδες στο δρόμο Καρδουκάρεμα-Αγ. Ανάργυρο-Τσαπαντή, που όλο μεγαλώνουν και γίνονται επουίνδυνας. Οι κάτοχοι αυτοκινήτων του χωριστόπρατώνουν να συγκρατηθεί ένα συνεργείο και να τις κλείσει με άσφαλτο ή σκυρόδεμα προτού ξορτώνουν περισσότερο, είναι δε διατεθειμένοι να καταβάλουν την αναλογία τους για τη δαπάνη. Επισήμαινουν επίσης, ότι ο κοινατικός χώρος στον Παράσχη τη Βρύση είναι για πάρουγκ και όχι για μόνιμα οικοδομικά υλικά, ακόμα στη στέφνα της Κρύας Βρύσης χρειάζεται μία αωλήνα για να συγκρατεί το δρόμο. Ευαγγητής Χρ. Γ. Πανταζέλας.
