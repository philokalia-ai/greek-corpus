# ΝΕΚΡΟΛΟΓΙΑ

Γεια σου πολυαγαπημένε Γιώργο! Γεια σου αγαπητό μου αδελφέ! Τώρα που μας έχεις φύγει, τώρα που σε χάσαμε για πάντα, ιδούμε πόσο ο πόθος κοιμάται μέσα μας, ό,τι πούμε πόση χαρά μας έδωσε. Θα μείνει για μας μια κάποια αντικαλύπτουσα και μια κάποια παρηγοριά αν είμαστε σίγουροι πως έφταξες στόν κάτω κόσμο που έπαιρνες θ' αντάμωσες με τους γονείς μας και τ' άλλα μας αδέρφια. Αλλά είναι κι' αυτό ένα σκοτάδι αδιαπέραστο που είναι κι' αυτό ένας γρίφος, που σε σαφή του απόνους, κόσμους δεν μπορέσαι σήμερα να ξεδιαλύνεις...

Γεια σου πολυαγαπημένε Γιώργο! Γεια σου αγαπητό μου αδελφέ... Δεν μπορώ να ξέρω αν η άδεια σου ψυχή γυρνάει στόν αιθέρα πάντα και γύρω από μας... Αν όμως γυρνάει θα δει πως όλοι μας εδώ είμαστε απαρηγόρητοι, και κλαίμε γυρνά τον ξαφνικό χαμό σου. Γεια σου πολυαγαπημένε Γιώργο! Γεια σου αγαπητό μου αδελφέ...
