# ● ΑΝΑΧΩΡΗΣΕΙΣ

Η κ. Αντωνία Χρ. Νίκου κόρη Γ. Χ. Κωστακνίλλη αναχώρησε δια Αυστραλίας. Της ευχόμαστε καλό Αυστραλιανό καλοκαίρι.

— Η Ηλίας Αντ. Καλατζής μετά της συζύγου του αναχώρησε για Κάνσας να δει τα παιδιά τους.
