# ΤΟ ΕΘΝΙΚΟ ΜΑΣ ΕΙΣΟΔΗΜΑ, ΟΙ ΕΛΙΕΣ, ΧΑΝΟΝΤΑΙ ΛΟΓΩ ΕΛΛΕΙΨΕΩΣ ΕΡΓΑΤΙΚΩΝ ΧΕΡΙΩΝ

Η Διεύθυνση Γεωργίας διαβεβαιώνει ότι, μόνο στη Λακωνία χάνονται 2 χιλ. τόνοι ελιάς. Οι γονείς, παρακαλούν τον κ. Υπουργό Παιδείας να εισάγουν το Γεωπονικό μάθημα, αλλά με πρακτική εξάσκηση, για να αγαπήσουν τα παιδιά την προγονική μας γη, και ως πρώτο βήμα να δώσει εντολή: τις ηλιόλουστες ημέρες, όλα τα σχολεία στις πορείες τους, να περνούν από τα ελαιοτριβήδια να μαζεύουν τις χαμένες ελιές που χάνονται και να τις παίρνουν δικές τους ή να πληρώνονται, καθώς οικονομούν μεγάλα ποσά για τις εκδρομές τους και άλλες ανάγκες ή έργα.
