# Στή χασαποταβέρνα τού Χωριού

Δέν είχα ποιόν να μού μαγειρέψει στό χωριό, κι' έτρωγα μόνον... κρέας! Κρέας βέβαια καθαρό, τρυφερό, άπό διαλεγμένα σφαστάρια τού βουνού που δέν τά βρίσκεις εύκολα σήμερα. Μερακλής ό χασάπης, τήν έχει οργανώσει μαστορι κά τή δουλειά του, και δέν άφηνε να φύγει κανένας παραπονεμένος. Τό πιά χοντρό τό δίνει για κατοκρόλα, τό μαλακτερο για τά φούρνο, και τό πιά τρυφερό για ψητό πάνω στά κάρβουνα ή τήν σχάρα.

Κι αυτή ή κατανάλωση άφορά τή μιά πλευρά που τροφοδοτεί τίς σβογένειες τού χωριού. Γιατί τό περαι σάπερα σφαστάρια του, τό φένει ό ίδιος (θάχετε άκούσει για τίς περίφημες εγκαύσεις που κουκουλιάζονται σέ κλει-στό φούρνο), και κάθε απόβραδο ή χασαποταβέρνα του γεμίζει από γιωταχθές από κάθε σημείο τού Νομού-, που τά καταβραχθίζουν.

Μέ τά ήλιόγερμα οι φίλοι μου, μού φωνάζουν έλα!
— Πάλι για κρέας;

— Φάε αγαπητέ μου, τώρα που τό βρίσκεις. Αύριο δέν ξέρεις τί γίνεται.

Συγούρι τή μία φορά, βετούλι τήν άλλη, κατοίκι και άρνε στή συνέχεια, άρχισα να μπαφιάζω και να τό βαρυέμαι. Για τί μέ μένανε, ολομάναχος στό σπίτι μου. δέν είχα κανέναν να μέ άλλοξοφαΐσει.

Τό χωριό μας χρειάζεται επιτακτικά μία χασαποταβέρνα. «Αν δέν υπάρχει κάποιος ειδικός, άς σπεύσει ένας να ειδικευθεί δωρεάν στίς σχολές τουρισμού, και σίγουρα θα φτιάξει τήν τύχη του.
