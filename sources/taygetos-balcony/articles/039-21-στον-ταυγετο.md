# ΣΤΟΝ ΤΑΎΓΕΤΟ

Τα ξέρω πως θάθελα πάλι να ξαναπάω στα πατροδικά μου τα βουνά να τα πατήσω πάλι· με τη λαχτάρα την παλιά και πάντα το γυρνάω να ξαναζήσω, να χαρώ τα ζηλιανά σου πάλι;

Να ψάξω μέσα στα δάση σου αναζητώντας ερέθισμα αγνού αέρα να πιω άφθονο νερό στις δροσερές πηγές σου, να ξανακατέβω τη γλυκιά του τσικόπουλου φλογέρα και τα γλυκογυρίσματα των πειρασμένων σου!

Στις ράχες σου πόσο πολύ να κάτσω ν' αγνάντευα τον κάμπο κάτω τη θολή γαλήνη, δεν δέχομαι και με το δάσκαλο τροφίμου να ακολουθήσω του δρόμου τη λιτανεία τη φύση κορδέλια!

Πώς λαχταρώ μέσα στη ψυχή μου ν' ακούσω πάλι την Γκύνη κι' αυτόν τον Χουχουλιάρικο που άνθρωπο να λέγουνε και τη ψυχτερινή δροσιά να σουλάθω να προπονήσω ένα στο ράμα τα νερά θα γλυστράγουσαν!

Να ζεσταθώ στόν πάγκο σου τη μυροδάτη λάκα να ρίχνω τη φλόγα τους, τα ψύλλα τους να πλέξω που μ' έχουν κάνει την καρδιά παντού σαν σάλουδο· πώς μ' έχουνε να, τώρα δα, σε 'σε να γυρνιτρέξω.

ΤΑΚΗΣ ΠΛ. ΣΤΑΘΑΚΟΣ
