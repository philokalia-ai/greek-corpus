# ΓΙΑ ΤΗΝ ΚΑΘΑΡΙΟΤΗΤΑ ΤΟΥ ΧΩΡΙΟΥ

Για να είναι το χωριό καθαρό, η Κοινότης μοίρασε σε όλα τα σπίτια, κλαστικά σκοπιδοδοχεία, για να συγκεντρώσουν τα σκουπίδια και κατόπιν να τα κάνε σε ένα λάκο, στον κήπο ή στην αυλή.

Η Κοινότης και όλοι που άγατούν τον καθαριότητα, παρακαλούν να τηρηθεί αυστηρά αυτό το μέτρο, και να μη ξαναφανεί ποτέ το παραμικρό σκοπίδι σε δρόμο. Είναι θέμα υγείας.
