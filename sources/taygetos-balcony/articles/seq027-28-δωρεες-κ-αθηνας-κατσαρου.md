# Δωρεές κ. Αθηνάς Κατσαρού

Από την κ. Αθηνά Δ. Κατσαρού, δια χειρός Χρ. Τσαγιώτη, δωρήθηκαν 108 χιλιάδες δρχ., στη μνήμη του προσφυγικού της συζύγου, για τη συμπλήρωση έτους από το θάνατό της, ως εξής:

| Αγ. Νικόλαος Γεωργιτσίου | 50.000 |
| Αγ. Αθανάσιος Γεωργιτσίου | 10.000 |
| Αγ. Ανάργυρος Γεωργιτσίου | 5.000 |
| Αγ. Β' Βαρβάρα Καστρίου | 3.000 |
| Ιερά Μονή Καστρίου | 10.000 |
| Ι. Μητρόπολη Σπάρτης - συνολικά | 20.000 |
| Εφημ. Γεωργιτσίου Νέα | 5.000 |
| Εφημ. Γεωργίτσι | 5.000 |
| Επίσης ενίσχυσε την εφημερίδα μας με 5.000 δρχ. ο Αρχιμανδρίτης κ. Βασίλειος Γιαννασάκης. |
