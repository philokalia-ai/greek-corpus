# Πρόγραμμα δασικών έργων

Κατά το τρέχον έτος, διατίθενται τα εξής ποσά κατά έργο:

|  — Για την προστασία των δασών | 15.000.000  |
| --- | --- |
|  — Για οίκον, αναδασώσεις | 15.000.000  |
|  — Για δασική ιδοποιία | 20.000.000  |
|  — Για έργα άνοψυχής | 8.000.000  |
|  — Για έργα βελτίωσης ύπορ, δασών | 8.000.000  |
|  — Για βελτίωση δασκοντάτων | 2.000.000  |
|  — Για δημιουργία δενδροστοιχιών | 500.000  |

Φέτος θα εκτελεστούν: έργα ιδοποιίας στα δάση Πάρνωνα και Ανατολικού Ταύγέτου για την απόληψη του λήμματος (ξυλείας) από τα δάση αυτά. Έργα προστασίας δασών με δημιουργία κατασκευής αντικυριών λωρίδων δρόμων στις κοινότητες Κροκεών - Γεωργιτσίου - Λογικανίκου - Καλλιθέας και στο Δήμο Μολάων. Έργα αναδασώσεων θα γίνουν στις κοινότητες Κροκεών - Βορδόνιας - Γεωργιτσίου. Έργα άνοψυχής σε διάφορες έκτασεις των δασών περιφέρειας κοινοτήτων Βρεαθένων - Βαρβακούς - Παπαδιπνίκων - Γεωργιτσίου - δήμου Γυθείου και στο δάσος Ταύγέτου.
