# ΕΥΧΑΡΙΣΤΗΡΙΟ

Σε όλους, που συμμετέχουν καθ' οποιονδήποτε τρόπο, στο βαθύ πένθος για τον θάνατο της προσφιλούς μας μητέρας Α. ΞΠΑΣΙΑΣ Η. ΤΣΕΡΩΤΑ εκφράζουμε τις θερμότερες ευχαριστίες μας.

Οι οικογένειες
ΝΙΚ. Π. ΤΣΕΡΩΤΑ
ΑΛΕΚΟΥ ΚΑΜΠΕΡΗ
