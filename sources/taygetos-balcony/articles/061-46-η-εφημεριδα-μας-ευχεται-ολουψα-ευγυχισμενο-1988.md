# Η ΕΦΗΜΕΡΙΔΑ ΜΑΣ ΕΥΧΕΤΑΙ ΟΛΟΥΨΑ ΕΥΓΥΧΙΣΜΕΝΟ 1988

Η εγγραφίδα μας αρχίζει υπέρμετρα για να εξασφαλίζει την εκτύπωση της. Τώρα με τις υπέροχες αναπράσιες αντιμετωπίζει εξίπλατο οικονομικό πρόκλημα για να καλύψει τα έξοδα της. Παρακαλεί δερμά στους καθυστρούν, να στείλουν τις σκέψεις με τους για να συνεχίσει, απρόσκεπτα τη χρήσιμη για τα χωριά έκδοσή της.
