# ΠΡΟΣΟΧΗ

Όσοι δεν δουνδρομυτεύσουν τα χωράφια τους, θα γίνουν δάσος.

Η υγεία δεν είναι κάτι που σου δίνουν αλλά κάτι που το αποκτάς. — Πίνετε νερό Γεωργιτσίου, είναι καλύτερο από του Λουτρακίου. —Καλύτερα να προλαβαίνεις παρά να θεραπεύεις.
