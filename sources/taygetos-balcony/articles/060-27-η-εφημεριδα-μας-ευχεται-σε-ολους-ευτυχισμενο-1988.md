# Η ΕΦΗΜΕΡΙΔΑ ΜΑΣ ΕΥΧΕΤΑΙ ΣΕ ΟΛΟΥΣ ΕΥΤΥΧΙΣΜΕΝΟ 1988

Η εγγραφίδα μας αρχίζει υπέρμετρα για να εξασφαλίζει την εκτύπωση της. Τώρα με τις υπέροχες αναγνώσεις αντιμετωπίζει σοβαρό οικονομικό πρόβλημα για να καλύψει τα έξοδα της. Παρακαλεί δε τους καθυστερημένους, να στείλουν τις συνδρομές τους για να συνεχίσει απρόσκοπτα τη χρήσιμη για τα χωριά έκδοσή της.
