# Γνώμες για τό πρώτο

Πανγεωργιτσιάνικα Συνέδριο

Η προσέλευση των απανταχού συμπατριωτών να αρχίσει στις αρχές Ιουλίου 1985, ομαδικά η μεμονωμένα. Φορέας υποδοχής θα είναι οι συγγενείς του καθενός, η κοινότητα, η εκκλησία, οι Σύλλογοι και όλοι οι συγχωρινοί.

Βασική επιδίωξη είναι να πραγματοποιηθεί ένα βήμα, για να πλησιάσουμε τις Κροκές που είχαν φέτος το... 31 συνέδριο τους! Διευκρινίζεται, ότι δεν μπορεί να γίνει ποτέ γενική επιστράτευση. Όσοι μπορούν και όσοι επιθυμούν θα έλθουν, και θα τους δεχτούμε με άνοιχτα τα χέρια και τις καρδιές μας. Χρήσιμο είναι να γνωστοποιούν που θα καταλύσουν, να ξέρει ο καθένας προκαταβολικά πως θα περάσει, ή μάλλον ότι θα κακοπεράσει και λιγάκι, διότι το Γεωργίτσι δεν έχει τις ανέσεις του εξωτερικού, αλλά αυτό, πρέπει να τους γοητεύει και να το θεωρήσουν τάμα και προσκύνημα στα πατρικά χώματα.

Γεωργιτσιάνοι του εξωτερικού, ευτυχώς έρχονται ορθόρμητα κάθε χρόνο. Εμείς οφείλουμε να προσέξουμε ιδιαίτερα, αυτούς που δεν γεννήθηκαν στο Γεωργίτσι και θα ξέρουν για πρώτη φορά. Να τους εξασφαλίσουμε Ξενοδοχείο και... φαγητό. Να τους ξεναγήσουμε ομαδικά, να οργανώσουμε όσο μπορούμε πολιτιστικές εκδηλώσεις και εκδρομές, στο δουνό, στα χωριά, στο Μυστρβ, Σπήλαια Διροΐ, ο γύρος Πελοποννήσου, Ολυμπία, Μυκῆνες, Επιδόχρο κλ. φέτος, κόστιζε το πολλών 3.000.

Για να φτιάξουμε δική μας Φιλαρμονική κλπ. είναι αδύνατον, ό,τι μπορούμε, θα το προσφέρουμε εγκάρδια. Στη προσπάθειά μας θα μας συμπαρασταθούν και οι αρμόδιοι. Αλλοίμονο αν ένας χρόνος
