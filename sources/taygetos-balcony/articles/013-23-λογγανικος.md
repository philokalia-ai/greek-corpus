# Λογγανίκος

Τα αιτήματα του Λογγανίκου είναι: να έπανελλουν τα κεκτημένα του μάς άφαίρεσαν, Αγροτικόν Ιατρείον, Αστυνομικός Σταθμός, να βελτιωθούν οι συγκοινωνίες και να γίνει έπανεκτίμησις των ζημιών στις ελπές.

Διά τον Ναόν του Αγίου Αθανασίου εις την συνοικίαν Γομοπέικα, ενεργείται έρανας προς επισκευήν του, μπορεί έκατος να προσφέρει τον όδολόν του εις τον εφημέριον Λογγανίκου π. Ιωάννην Ψαθάν και να λάβει απόδειξιν.
