# Αποσημειώθηκαν οι καταστροφές '87

Για τις καταστροφές που υπέστησαν οι καλλιέργειες από τις δεσμινίες του περσινού Μαρτίου πληρώθηκαν μέχρι τώρα: Βελλάνο 14.713 εκ. Γεωργίου 6.042. Αγάριον 4.045. Αγ. Κων/νος 3.724. Αλωρικό 5.648. Περιβάλλον 3.740. Βαρδένια 15.330. Καττέρι 15.391. Λαγκανίνας 15.442. Εγυρίθηκαν και οι αιτήσεις των μικροσυνταξιασμών των οποίων τα αισθάριστα εισόδημα δεν υπερβαίνει τις 600.000 δρχ.
